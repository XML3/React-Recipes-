# Recipe Checker with React.js
A simple front-end React.js project designed to elevate your culinary journey by helping users explore recipes that fit their specific dietary needs and preferences.

## Features
Search Recipes: Users can search for recipes by keywords and apply dietary preferences such as labels, diet labels, cautions, and health labels.

Recipe Cards: Recipes are displayed on color-coded cards that indicate whether the recipe is Vegetarian or Vegan. Caution and dietary preference labels are also highlighted in color for quick reference.

Surprise Recipe Buttons:

Random Recipe Button: Generates a random recipe from all available recipes.

Random Vegetarian/Vegan Recipe Button: Generates a random recipe that is specifically either Vegetarian or Vegan, catering to users with those dietary preferences.

This project leverages React.js and Chakra UI to provide a clean, intuitive user interface and a delightful culinary exploration experience.

Technologies Used
React.js: A JavaScript library for building user interfaces.

Chakra UI: A simple, modular, and accessible component library for React.

Features in Detail
Recipe Search: The search functionality allows users to filter recipes based on specific criteria such as labels, diet types, and health warnings.

Dietary Preferences: Recipes are displayed with color-coded labels indicating their dietary status (Vegetarian, Vegan, etc.).

Surprise Buttons:

The Random Recipe Button delivers a random recipe, broadening the users' culinary options.

The Random Vegetarian/Vegan Recipe Button focuses on delivering recipes suitable for specific diets, helping users easily find meals that fit their dietary restrictions.

## Getting Started
Prerequisites
Node.js and npm should be installed on your machine to run the project locally.

Installation
Clone the repository to your local machine:

bash
git clone [repo]
Navigate into the project directory:

bash
cd recipe-checker-react
Install the required dependencies:

bash
npm install
Start the development server:

bash
npm start
This will launch the front-end application locally in your browser at http://localhost:3000.

Folder Structure
src/: Contains all the source code for the React app.

components/: Contains reusable components such as recipe cards, search bars, and buttons.

pages/: Contains different pages (such as the main recipe page).
